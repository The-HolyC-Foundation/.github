# The HolyC Foundation

Low-level systems research and development. Currently implementing a native internet stack for TempleOS from scratch using HolyC.

## Focus Areas
* **Kernel Networking**: Ring 0 packet handling and driver development.
* **Network Stack**: TCP/IPv4, UDP, and ICMP implementation in HolyC.
* **Bare Metal**: Direct hardware interaction without unnecessary abstractions.

## Philosophy
* No bloat.
* 64-bit x86_64 purity.
* Ring 0 only.

## Contributions
All Pull Requests are automatically assigned to @Sh1n4r4 for review. 
Knowledge of HolyC and x86_64 Assembly is required.
